# PlanT
PlanT는 사용자들이 현실적인 계획을 수립하고 꾸준히 실천하여 개인의 필요에 부합하는 성장습관을 형성할 수 있도록 지원하는 앱입니다.  
  
나다운 작은 성장 → 거창한 목표가 아니라, 나만의 작은 루틴에서 시작합니다.  
Plan + Tree → 작은 계획들이 모여 큰 나무로 성장하는 과정을 경험합니다.  
함께 성장하는 나무 → 나와 함께 자라는 나무를 보며 성취감을 느낄 수 있습니다.  

# 주요기능
- 작은 습관들을 탬플릿으로 제시  
- 꾸준하게 습관을 이어가도록 알림 제공  
- 습관이 만들어지는 과정을 식물 키우기 그래픽으로 비유해 보여주기
